# 发布记录

## v0.1.0-demo.1 — 2026-10-21

首个 Demo 预发布版本，以同日已验证的 Windows x64 插件迁移快照为基础。

- 提供一键离线安装入口、完整插件依赖、中文安装说明、插件清单及 SHA-256 校验。
- 清单记录 26 个 bundle（4 个内置、22 个另装）；安装 20 个兼容第三方包及一个启停状态辅助 bundle。
- 保留原环境 233 条组合插件行的布尔启停状态。236 个加载器条目含内核自动条目，不代表独立包数量。
- 两个不兼容第三方包保留文件但跳过安装，不授予版本豁免。
- 目标为 Windows x64、DSH 内核 0.2.1-rc.2、新初始化的 Desktop profile。
- 原快照通过独立 DSH_HOME 的官方 CLI 安装、链接、版本和组合状态验证。本次仅增加发布标记与说明，并重新验证完整文件和 ZIP 校验。

未在第二台物理电脑验证 Desktop 图形界面或需要个人账号的插件功能。安装包不含账号、模型密钥、聊天、浏览器用户数据或 Zotero 文献库。第三方插件的版权与许可按原包保留。
