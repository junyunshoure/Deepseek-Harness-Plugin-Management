# DSH-Plugins v2.0.1-patch.1 — 对齐提问协议（ALIGNMENT_PROTOCOL v1.0）

这是 **v2.0.0 整合包的一个小补丁**（约 30 KB），不需要重装整包，也不改任何插件代码。

它只做一件事：**给 DSH 的 AI agent 装上一条硬规则 —— 每次任务动手前，先按任务难度和广度提出若干条对齐问题，把方案对齐，再执行。**

---

## 1. 装上之后会变成什么样

| 任务类型 | 以前 | 现在（装完补丁） |
| --- | --- | --- |
| 查一条命令、读一个配置 | 直接答 | 直接答（不打扰） |
| 改一个文件、写一份文档 | 直接做 | 先问 3–6 个问题（每个带推荐值） |
| 跨模块 / 代码+文档+配置联动 | 直接做，边做边问 | 先问 8–15 个，对齐后动手 |
| 发版 / 动全局环境 / 删数据 / 推仓库 | 直接做 | 先问 15–30 个（最多 50），含验收与回滚 |

外加一条你现在就想要的细节：

> **执行参数（深度档位）必须单独用一个交互卡片来问，不能混在长清单里。**

规则全文在 [`ALIGNMENT-PROTOCOL.md`](ALIGNMENT-PROTOCOL.md)，装进 `~/.dsh/AGENTS.md` 时带起止标记，方便以后升级或卸载。

## 2. 安装（Windows）

1. 解压本补丁到一个**固定**目录（例如 `D:\dsh-patch\`），不要放在会随手删掉的下载目录。
2. 双击 `CHECK.cmd` — 只做校验和预演，**不改任何文件**，先看一眼要做的动作。
3. 双击 `APPLY.cmd` — 校验 SHA-256 → 备份现有 `AGENTS.md` → 写入/替换标记块 → 回读验证。
4. **重启 DSH**（或直接开一个新会话）。全局指令是每个会话开始时读的，旧会话不会热更新。

安装位置：`%USERPROFILE%\.dsh\AGENTS.md`
备份位置：`%LOCALAPPDATA%\DSHPluginMigration\align-protocol-20261029\backup-<时间戳>\AGENTS.md`
安装报告：同上目录下的 `patch-result.json`（含前后字符数、哈希、回滚命令）

## 3. 安装（macOS / Linux）

```bash
bash apply.command --check     # 预演
bash apply.command             # 安装
bash apply.command --uninstall # 卸载（只删标记块）
```

安装位置：`~/.dsh/AGENTS.md`

---

## 4. 卸载与回滚

- **只想撤掉补丁**：双击 `UNINSTALL.cmd`（macOS 用 `apply.command --uninstall`）。它只删 `ALIGNMENT_PROTOCOL v1.0` 标记块，你自己的其他指令一个字都不动。
- **想整份恢复**：把备份目录里的 `AGENTS.md` 覆盖回去即可。
- 卸载同样会先备份，所以可以反复装卸。

---

## 5. 安全性说明

- 补丁包自带 `checksums.json`，安装器**先逐个文件校验 SHA-256**，任何一个不一致就直接停，不写盘。
- 只做「追加」或「替换自带标记块」两种动作，**从不整份覆盖**你的 `AGENTS.md`。
- 没有网络访问、没有服务、没有凭据、没有后台常驻；全部逻辑就是一次文本写入 + 一次回读比对。
- `-Target` 参数可以把补丁打到别的路径（例如某个项目的 `AGENTS.md`），默认只打全局。

## 6. 常见问题

**Q：装完没有任何反应？**
全局指令在会话启动时读取，旧会话不会生效。开一个新会话，给它一个中等复杂度的任务，看它是否先给编号清单。

**Q：会不会以后每句话都被反问一堆？**
不会。协议里有「不触发白名单」：只读查询、单条命令、你已锁定的方案、你说「直接做/别问」、紧急排障，都直接做。

**Q：和我自己的 `AGENTS.md` 冲突吗？**
只追加块，不覆盖。它写的是「什么时候问、问几条、每条带什么」，不覆盖你原有的任何偏好。

**Q：这个补丁会跟着 v2.0.0 整包自动装上吗？**
不会。v2.0.0 整包是 2026-10-28 打的，不含本补丁。装整包之后再跑一次 `APPLY.cmd` 即可；重复运行是幂等的（替换同一个标记块）。
