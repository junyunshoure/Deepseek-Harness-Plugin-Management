# 对齐提问协议 v1.0 —— 逐条解释（小白向）

> 一句话：**开工前先问，问多少看任务多大；问完再动手，动了就报清楚。**

这份文档解释补丁装进你 `AGENTS.md` 的那段规则到底在管什么。要改规则，改补丁里的 `ALIGNMENT-PROTOCOL.md` 再重跑安装器，别手改 `AGENTS.md`（下次升级会被替换掉）。

---

## 为什么要有它

AI 干活最常见的两种翻车：

1. **不打招呼就开工** —— 方向猜错，做完才发现不是你要的，浪费时间还可能改坏东西。
2. **什么都要问一遍** —— 查个端口也反问三句，烦。

这个协议就是给这两头划一条线：**大活先对齐，小活别啰嗦。**

---

## 一、难度四档 → 问题条数

| 档 | 什么算这一档 | 要问几条 |
| --- | --- | --- |
| D0 微改 | 查命令、读文件、看配置、改一个变量 | 0–2 |
| D1 常规 | 改一个文件、写一份文档、跑一次构建、常规排障 | 3–6 |
| D2 跨面 | 多文件多步骤、代码 + 文档 + 配置一起动、要在几种方案里选 | 8–15 |
| D3 不可逆 | 发版、推仓库、动全局环境或凭据、删数据、跨机器分发、重打大包 | 15–30（最多 50） |

**取最高项**：任务里只要夹了一个 D3 动作（比如「改完顺便发个版」），整件事按 D3 问。

---

## 二、每条问题必须带三样东西

1. **问题本身** —— 一句话能回答，不是"你觉得怎么样"。
2. **推荐默认值** —— 可以直接执行的那一个（A/B/C 里点名 A）。
3. **一句取舍** —— 选它得到什么、放弃什么。

末尾固定两句：

- 「回『全部按推荐』即开工」
- 「只改关键项就写『第 3 题选 B』，其余按推荐」

问题会按 **A 定义与范围 / B 内容与数量 / C 落点与打包 / D 版本与发布 / E 验收与回滚** 分组编号，方便你只挑要改的那条。

---

## 三、执行参数：单独一张卡片（本次特别要求）

**深度档位这类"执行参数"必须单独问，而且必须用交互卡片弹出来**，不允许混进几十条方案清单里。

理由很实际：清单长了，人眼会漏；档位又决定后面所有推演的长度，漏了等于整轮跑偏。

卡片长这样：

```
深度档位：1 快答 / 2 标准 / 3 严格四层推演
建议 3 —— 改全局指令 + 打包 + 发版，不可逆项多
（不回按 2）
```

- 卡片里只放执行参数（必要时并列 ≤3 个参数），不掺方案问题。
- 你不回，就按推荐值走，并在收尾时注明"档位按推荐 X 执行"。
- **方案问题只有在"关键决策 ≤4 个"时才额外用卡片**；超过 4 个一律用文字编号清单，卡片只负责执行参数。

---

## 四、四种档位下的出题策略

| 你的 `DEPTH_MODE` | 行为 |
| --- | --- |
| `ask` | 先弹卡片定档 → D0/D1 出 3–6 问，D2/D3 全量出 |
| `auto` | D0/D1 静默直接做；D2/D3 才弹卡片 + 出清单 |
| `deep` | 卡片 + 全量清单，并按四层（理论 → 组件 → 流程 → 参数/代码）展开 |
| `fast` | 卡片可省；只出「落点 / 范围 / 发布」3 个关键问题 |

顺序固定：**先卡片定档，再按档决定出不出清单**，不会一个开场问你两遍。

---

## 五、这几种情况不该问（白名单）

- 纯事实查询、读文件/日志/配置、单条只读命令。
- 你已经在本会话锁定方案，或说了「直接做 / 别问 / 快 / 按推荐」。
- 已经对齐过的方案里的下一步（同一件事不重复问）。
- 紧急排障：先止血，止血动作不受门禁限制，止血后再补对齐。
- 宿主规则本来就禁止请示的场合。
- 子任务已被上级 agent 对齐过（brief 里写着结论与档位）。

---

## 六、做完要给"对齐回执"

不是一句"已完成"，而是五段：

1. 哪些**按推荐**执行
2. 哪些**被你改单**
3. **实测证据**（命令输出、哈希、比对结果）
4. **未验证 / 遗留**项（单独列，不许混进"已完成"）
5. **回滚路径**（备份在哪、怎么恢复）

---

## 七、子代理也一样

派 subagent / teammate 时，brief 里要写明：适用 `ALIGNMENT_PROTOCOL v1.0`、难度档是什么、已对齐的结论是什么。子代理不许因为"已对齐"就跳过证据核验，也不许反过来再向你重复提问。

---

## 八、怎么改、怎么撤

- **改规则**：编辑本补丁的 `ALIGNMENT-PROTOCOL.md`（保留首尾那两行标记），然后重跑 `APPLY.cmd`，它是幂等的（替换同一个标记块）。
- **撤掉**：`UNINSTALL.cmd`，只删标记块；或把备份的 `AGENTS.md` 覆盖回去。
- **升级**：以后补丁版本号变了，直接装新补丁，会覆盖旧块，不会叠加两份。

---

## 九、判定自己装成功了没

1. 开一个**新**会话（旧会话不生效）。
2. 给它一个 D1 级任务，例如「帮我把 README 的安装步骤改成三步」。
3. 正确表现：先弹一张**档位卡片**，再给 3–6 条带推荐值的编号问题，**等你回**。
4. 再给它一个 D0 级任务，例如「读一下 `~/.dsh/AGENTS.md` 有多少行」。
5. 正确表现：直接给结果，不弹卡片、不出清单。
